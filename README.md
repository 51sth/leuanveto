# Leuanveto — harjoituspäiväkirja (versio 1.3)

Staattinen, itsenäinen verkkosovellus. Säilytetty alkuperäisen v1.3-julkaisun sovellustiedostot muuttamattomina.

## GitHub Pages

Julkaise `main`-haaran juuresta (`/(root)`) GitHub Pagesissa. `index.html` toimii aloitussivuna ja muut tiedostot ovat suhteellisissa poluissa.

Odotettu osoite repositorion `51sth/leuanveto` kautta: `https://51sth.github.io/leuanveto/`. Osoite toimii vasta GitHub Pages -julkaisun valmistuttua.

## Tallennetut harjoitukset

Harjoitukset tallentuvat selaimen paikalliseen tallennustilaan (localStorage), eivät GitHubiin. Netlify-osoitteessa tallennetut harjoitukset eivät siirry automaattisesti GitHub Pages -osoitteeseen. Käytä vanhassa sovelluksessa **Historia → Tallenna varmuuskopio** ja uudessa **Historia → Palauta varmuuskopio**. Älä lataa harjoitushistoriaa julkiseen GitHub-repositorioon.

## Päivittäminen

Kun päivität GitHub-repositorion tiedostoja samalla haaralla, GitHub Pages päivittää sovelluksen samaan verkko-osoitteeseen.
